DrawerCraft PWA - upload contents of this folder, NOT the zip itself, to the root of your public GitHub repository.

GitHub: Code > Add file > Upload files; drag index.html, manifest.webmanifest, sw.js and the icons folder. Commit changes.
GitHub: Settings > Pages > Build and deployment > Deploy from a branch > main, /(root) > Save.
Site URL: https://olaekvall.github.io/Drawercraft/ (case sensitive; use actual GitHub-generated Pages URL).
When the site is live, enter its URL into https://www.pwabuilder.com/.

Reminder: This is a PWA packaging prototype; verify cut dimensions and cutting layouts before real woodworking.
